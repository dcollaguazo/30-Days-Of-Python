# My 30 Days of Python Learning Plan

## Why I'm doing this

This is a self-imposed challenge to dust off my Python skills and rebuild confidence writing Python independently.

I'm using the 30 Days of Python curriculum as a structured foundation while also practicing debugging, testing, problem solving, and writing code without relying too heavily on tutorials or AI.

## Time commitment

My target is at least **7 hours per week**, ideally around **1 hour per day**.

I am not treating "30 Days" as a strict 30-calendar-day deadline. I want to finish as quickly as my life allows while prioritizing understanding and retention over simply completing the exercises.

## Goal

My goal is to become **interview-ready in Python** and comfortable enough to use Python independently in software engineering work.

Success means more than finishing the curriculum. I want to be able to:

- solve problems independently with Python
- read and debug Python code
- explain the code I write
- write tests and verify my work
- use documentation effectively when I don't know something
- apply what I learn to real projects

## Bigger picture

This challenge is one part of a broader effort to strengthen my software engineering skills.

In parallel, I am building other software projects and developing my portfolio. The Python skills I practice here should transfer into those projects rather than remain isolated course exercises.

## Working principle

**A lesson is not complete because I finished the exercises. It is complete when I can demonstrate that I understand and can use the skill.**
